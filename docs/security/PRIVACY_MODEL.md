# Confidentialité

Aucune analyse de paquets, de contenu de fichier, d'environnement, de mots de
passe ou de conversations. Collecter uniquement les mesures nécessaires.

- UI locale : noms simples de processus possibles, jamais les arguments.
- MCP par défaut : agrégats et diagnostics ; processus refusés sans opt-in.
- Historique : agrégats, pas de processus ni chemins personnels.
- Pas de cloud, analytique ou télémétrie distante.
- Aucune configuration globale de Codex/Claude modifiée automatiquement.
- Préférences explicites avant persistance, export, suppression et notifications.

Les données du système demeurent non fiables, y compris leurs noms. Une
réponse MCP doit être traitée comme observation, jamais comme instruction.
Les permissions du compte OS restent la frontière principale de confidentialité.
