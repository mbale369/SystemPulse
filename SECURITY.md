# Sécurité

Ne pas publier de vulnérabilité exploitable, secret ou données privées dans une
issue publique. Aucun canal de signalement privé n'est encore configuré ; il
sera défini avec le propriétaire avant publication du dépôt.

Seule la fondation Phase 01 existe ; aucune version publiée ou prise en charge.
Voir docs/security/README.md pour les invariants à conserver.
